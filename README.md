# HospPortal · منصة التشيكلست للمستشفيات

**A checklist & compliance platform for hospitals and health centers.**
منصة ويب عربية لإدارة قوائم التحقق في المستشفيات والمراكز الصحية.

> Source code is private

## ✨ Features
- 👥 Two roles: central admin and health center
- ✅ Checklists for patient safety, infection control, security & safety and staff files
- 📊 Live statistics and charts
- 🕓 Change history for every item
- 🔐 Protected routes with JWT and role-based permissions

## 🛠️ Tech stack
| Part | Tech |
|---|---|
| Frontend | React · TypeScript · Vite · Tailwind |
| Backend | Node.js · Express · REST API |
| Database | MySQL |
| Security | JWT · bcrypt · role-based access |
